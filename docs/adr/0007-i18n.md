# ADR 0007 — Dictionary-based IT/EN i18n without a framework

**Status:** Accepted · **Date:** 2026-11-20

## Context
Two languages, ~50 strings. i18next/FormatJS would dominate bundle size.

## Decision
Plain dictionaries in `src/i18n.js`, `data-i18n` attributes in the template, `{placeholder}` interpolation. Locale resolution: saved choice → `navigator.languages` → Italian. `<html lang>` is updated on switch. Tests enforce identical key sets and placeholder parity.

## Consequences
- ✅ Adding a language = one dictionary + one code in `SUPPORTED`; tests flag omissions.
- ⚠️ No plural rules or ICU formatting; sufficient for current strings.
- ⚠️ Native widgets (e.g. the file picker's "Choose file") follow the browser's language, not the app's.
